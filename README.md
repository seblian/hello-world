## Présent — 法语直陈式现在时变位练习

打开 [`conjugaison-present.html`](./conjugaison-present.html)（双击或用本地静态服务器均可）。

包含：

- **第一组**规则 `-er` 动词（含 manger / commencer / acheter 等拼写变化）
- **第二组**规则 `-ir` 动词（finir 型）
- **常见第三组**不规则动词（être, avoir, aller, faire, pouvoir…）

练习方式：单空填空或完整六人称变位表；可选重音容错；下方有变位速查。
